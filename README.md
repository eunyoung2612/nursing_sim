# 상부위장관출혈 ICU 입원 1일차 시뮬레이션 (Streamlit)

간호학생 보강용 앱입니다. 57세 남자 환자(백OO)의 입원 1일차 차트를 4개 장면으로 나누어 보여줍니다.

| 장면 | 차트 시각 | 공개 (09:00 시작 기준) | 학습 목적 | 마지막 안내 |
|---|---|---|---|---|
| 1 | 14:00 ICU 입실 | 09:00 | 중환자실 입실한 환자 안내하기 | Part A 작성 |
| 2 | 16:40 Angiography 후 ICU transfer | 11:00 | angiography 이후 환자 간호하기 | Part B 작성 |
| 3 | 18:00 흉부 통증 | 14:00 | 흉통 사정하기 | Part C 작성 |
| 4 | 19:00 환자의 불안 | 16:00 | 환자의 불안 사정하기 | Part D 작성 + 간호과정 제출 |

- 각 장면은 그 시각까지의 차트(의사지시, 활력징후, 투약기록, 간호기록, 검사결과)만 보여줍니다.
- **교수자가 수업을 시작해야 열립니다.** 사이드바 '교수자'에 코드를 넣고 **▶️ 수업 시작**을 누르면
  장면 1이 바로 열리고, 장면 2·3·4는 시작 2·5·7시간 후에 자동으로 열립니다 (09:00 시작 → 11:00·14:00·16:00).
- 교수자는 '장면 N 지금 열기'로 미리 열 수 있고, '수업 종료'로 다시 모두 잠글 수 있습니다.
- 잠긴 장면은 학생 메뉴에 보이지 않으며, 열리는 시각이 되면 30초 안에 자동으로 나타납니다.
- 수업 상태는 모든 학생에게 공통입니다. 앱이 재시작(Reboot)되면 수업 상태가 초기화될 수 있으니 다시 '수업 시작'을 누르세요.

## 파일
```
app.py              # 시작 페이지 + 장면 이동
core/data.py        # 환자 차트 데이터
core/scenes.py      # 장면 설정 (상황, 학습 목적, 과제, 마지막 안내, 공개 시각)
core/ui.py          # 화면, 시간 잠금
requirements.txt
```

## Streamlit Secrets
share.streamlit.io → 내 앱 ⋮ → Settings → Secrets
```
INSTRUCTOR_CODE = "10718"
LOCK_ENABLED = true
```

※ 교육용 가상 사례이며 실제 환자 정보가 아닙니다.
